# 原始需求整理

题号：T007

要求实现一个基于 Qt5.9 / C++11 / qmake 的协议生成与发送工具，满足：

1. 读取自定义 XML 协议。
2. 支持 `DEC/INT/BIN/OCT/HEX/FLT/DBL/STRING/FLAG` 等共 15 类常见字段类型。
3. 能随机生成字段值。
4. 可配置发送频率、发送数量、目标 IP、端口。
5. 发送数量为空时，持续发送直到用户停止。
6. 通过 UDP 发送。
7. 展示发送进度，并写入 SQLite 日志。
8. 支持按时间、协议、IP 查询日志。
9. 提供本地 loopback 或生成器性能基准，并分析最高频率。
